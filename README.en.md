# pure-output-skill

[中文](README.md) | English

A skill for cleaning up writing and deliverables.

It addresses:

1. Attention drift that produces output without substance (“Dongpo pork”).

2. Process notes leaking into code comments.

3. User emphasis leaking into documents (same class of problem as above).

4. Too many test cases appearing in documents.

## Install

Ask your agent to run:

```bash
npx skills add BranchCrypto/pure-output-skill
```
